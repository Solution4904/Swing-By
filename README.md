# 개요

이름 : Swing By<br>
설명 : 현재 사용자의 위치 정보를 기반으로 등록해두었던 메모의 장소가 일정 거리 안에 존재할 때 이를 알려주는 메모 앱

# 필요 기술

- GPS (카카오맵 or 네이버맵 or 구글맵)
- 서버 (파이어베이스) or ROOM?
- 푸시 알림 (FCM) + Notification
- 위젯
- 백그라운드 서비스
- (추가 기능) SNS 계정 연동 (카카오톡, 네이버, 구글)

# 작업 이후 해야하는 것

- 전체 코드 리뷰
- 이메일 가입 시 이메일조건 및 비밀번호 6자리이상 등의 내부 규칙이 있음. 레이아웃이나 Toast로 명시할 것
- 설정 만들것 (주변 검색 시 거리(km)나 결과 갯수, 로그아웃, 초기화 등) + 이전 로그인 데이터가 있다면 앱 실행과 동시에 자동 로그인. & 설정에서 로그아웃 시 기존 로그인 창.
- 작업이 지연되는 작업들에 프로그래스 화면 넣고 터치를 막을 것
- 메모 리스트 정렬 기준 살펴볼 것 (지금은... 자기 마음대로 순서인 거 같은데?)
- class에 <>는 어떻게 쓰이는 거고, ::class.java나 ::inflater는 어떻게 쓰이는 거지?
